# IT-Portfolio
Welcome to my IT portfolio!

I am currently building hands-on experience in IT while studying for the CompTIA A+ and then later additional certifications like the CCNA. I created this repository to document my progress, apply the concepts I am learning through practical labs, and develop skills that are relevant to real-world IT support and networking environments.

# About This Portfolio
This repository contains hands-on projects and labs covering areas such as: 
  * Computer hardware
  * Networking
  * Ethernet cabling and structured cabling
  * Hardware and network troubleshooting
  * Operating systems
  * IT support concepts
  * More to come!

My projects include documentation of the work I performed, photos and videos of the process, testing and verification, problems I encountered, troubleshooting steps, and what I learned from each experience.

# My Goals
My current goal is to continue developing practical IT skills alongside my studies and build a strong foundation for an entry-level career in IT or network engineering.

As my knowledge grows, I plan to expand this portfolio beyond individual hardware and cabling labs into more complete networking, system administration, and troubleshooting projects.

This portfolio will continue to grow as I learn new technologies and gain more hands-on experience.
