# Ethernet Cable Termination

# Overview
For this project, I practiced terminating Cat6 Ethernet cable with RJ45 connectors.The goal was to learn the proper process for preparing Ethernet cable, arranging the conductors according to the correct wiring standard, terminating the cable, and verifying that the finished cable worked correctly using a cable tester. 

I documented the process with photos and videos and successfully created working Ethernet cables.

# Equipment Used
  * Cat6 Ethernet cable
  * RJ45 pass-through connectors
  * Rj45 crimping tool
  * Ethernet cable tester
  * Cable stripper/cutter

# T568B Wiring Standard
For my straight-through Ethernet cable, I used the T568B wiring standard on both ends of the cable.

The T568B pin order is:
1. White/Orange
2. Orange
3. White/Green
4. Blue
5. White/Blue
6. Green
7. White/Brown
8. Brown

# Cable Termination Process

# 1. Preparing the Cable
I cut the Cat6 cable to the length needed and carefully removed a portion of the outer jacket to expose the four twisted pairs inside. I then cut the spline and rip cord off.

# 2. Arranging the Conductors
I untwisted, straighten and arranged the eight conductors according to the T568B wiring standard. Before inserting the conductors into the RJ45 connector, I trimmed the conductors and checked the order to make sure each conductor was in the correct position.

# 3. Installing the RJ45 Connector
Once the conductors were arranged correctly, I inserted them into the pass-through RJ45 connector. The pass-through design allowed me to verify that all eight conductors were in the correct order and had reached the end of the connector before crimping.

# 4. Crimping the Connector
I placed the RJ45 connector into the crimping tool and crimped the connector to secure the conductors and complete the termination. I repeated the process on the other end of the cable using the same T568B wiring standard.

# 5. Testing the Cable
After terminating both ends, I connected the finished cable to an Ethernet cable tester. The tester verified continuity across all eight conductors; therefore, the test passed.

# Troubleshooting
During the termination process, I learned that even a small problem with one of the conductors can cause the cable to fail testing. When a termination did not work correctly, I inspected the connector and the cable tester results, cut off the failed termination, prepared the cable again, installed a new RJ45 connector, and retested the cable. After correcting the termination, the cable successfully passed the cable tester. This helped me understand why testing and verification are important after terminating network cabling.

# Final Result
I successfully created and tested working Cat6 Ethernet cables using RJ45 connectors and the T568B wiring standard.
Through this project, I gained hands-on experience with:
  * Preparing Ethernet cable for termination
  * Identifying and arranging twisted-pair conductors
  * Following the T568B wiring standard
  * Installing pass-through RJ45 connectors
  * Using an RJ45 crimping tool
  * Testing Ethernet cables
  * Identifying and correcting termination problems

# What I learned
This project helped me understand that Ethernet cable termination requires more than simply arranging wires in the correct order. Proper cable preparation, ensuring that each conductor is fully inserted and in the proper order, and testing the completed cable are all important parts of creating a reliable connection. I also gained experience troubleshooting an unsuccessful termination and learned to use the results from a cable tester to verify my work.
